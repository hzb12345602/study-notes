# 26.10.13 软件、操作系统与硬件：三条线的互相推动

> 学习笔记。主线：硬件、操作系统、软件/编程三条线并行梳理，看它们如何互相推动。
> 核心关系：**硬件提供算力，OS 管理算力，软件消费算力**。每一次硬件形态变化，都催生新的 OS 和编程范式。

## 一、1950 年代：晶体管计算机与"没有 OS 的裸机"

- **硬件**：1945 年 ENIAC 是**真空管**计算机（不是晶体管）；1953 年曼彻斯特的 Transistor Computer 才是第一台晶体管计算机；1956 年 MIT 的 TX-0 是早期有影响力的晶体管计算机
- **编程**：手写机器码，拨动开关 / 打孔纸带输入；1950 年代中后期汇编语言出现（IBM 704 的 SAP 汇编器）
- **OS**：1956 年 GM-NAA I/O 是第一个 OS 雏形（IBM 704 批处理），但只是**批处理监控程序**，负责自动加载下一个作业——本质仍是裸机，没有进程、虚拟内存、文件系统

**核心矛盾**：硬件太贵，人太慢。批处理监控程序是为了让 CPU 少等人。

## 二、1960 年代：OS 诞生、编译器成熟、C 语言前夜

- **硬件**：集成电路（IC）出现；IBM System/360（1964）是第一个指令集兼容的计算机家族
- **OS**：1961 年 CTSS（兼容分时系统）让多用户同时用一台计算机；1964 年 Multics 启动，引入分时、虚拟内存、分级文件系统；1969 年 Unix 诞生（Ken Thompson 用汇编写的）
- **语言**：1957 年 FORTRAN（第一个高级语言编译器）、1958 年 LISP、1959 年 COBOL；编译器开始能做基本优化

**核心矛盾**：硬件开始支持多用户，但软件还停留在汇编。高级语言和 OS 同时起步。

## 三、1970 年代：C 语言、Unix 重写、微处理器萌芽

- **硬件**：1971 年 Intel 4004（第一个商用微处理器）、1974 年 Intel 8080
- **OS**：1973 年 Dennis Ritchie 用 **C 语言重写 Unix**——Unix 不再依赖特定硬件汇编，可以移植；C 和 Unix 互相成就
- **语言**：1972 年 C 语言诞生；1970 年代中后期编译器优化技术成熟（数据流分析、循环优化）

**核心矛盾**：硬件开始变小变便宜，但软件还绑在特定硬件上。C + Unix 打破了这堵墙。

## 四、1980 年代：个人 PC 普及、GUI 革命、ARM 诞生

- **硬件**：1981 年 IBM PC（开放架构，MS-DOS）；1984 年 Apple Macintosh（图形界面+鼠标）；1983 年 ARM 诞生，1985 年第一颗 ARM 芯片
- **OS**：MS-DOS（1981）、Mac System（1984）、Windows 1.0（1985）；Linux 还没出现（1991 才诞生）
- **软件**：上层软件井喷（文字处理、电子表格、游戏）；GCC（1987）、Borland Turbo C（1987）

**核心矛盾**：硬件便宜了，但普通用户不会用命令行。GUI 解决了这个问题。

## 五、1990 年代：Linux 诞生、互联网爆发、ARM 进入移动

- **硬件**：PC 性能飞速提升，互联网基础设施铺开；ARM 低功耗优势显现但未统治移动端
- **OS**：1991 年 Linux 诞生（Linus Torvalds，开源+Unix 兼容）；1995 年 Windows 95 让 GUI 普及；嵌入式 OS（VxWorks、QNX）在工业领域成熟
- **软件**：互联网爆发（浏览器、Web 服务器、Java 1995）；开源运动兴起（Apache、MySQL、PHP）

**核心矛盾**：PC 和互联网连接了世界，但移动端还没有真正的低功耗方案。

## 六、2000 年代：ARM 统治移动、GPU 从图形走向通用

- **硬件**：2007 年 iPhone（ARM+触屏+移动 OS）；2006 年 NVIDIA CUDA（GPU 从图形渲染走向通用计算）；2007 年 Android 开源
- **OS**：iOS、Android 成为移动端两大 OS；Linux 统治服务器；FreeRTOS 在 MCU 领域普及
- **软件**：移动 App 生态爆发；深度学习框架萌芽（Theano、Caffe）

**核心矛盾**：移动端算力有限，但 AI 需求开始增长。GPU 的并行能力被重新发现。

## 七、2010 年代至今：AI 革命、GPU 成为核心、自然语言编程

- **硬件**：GPU 从图形加速器变成 AI 训练核心；TPU、NPU 专用 AI 加速器出现；RISC-V 开源指令集兴起挑战 ARM/x86
- **OS**：Linux 在 AI 服务器端统治；实时 OS 与 Linux 共存（Zynq、Jetson 等异构平台）
- **软件**：2012 年 AlexNet 引爆深度学习；2015 年 TensorFlow、2016 年 PyTorch；2020 年代大语言模型（GPT 系列）；自然语言编程（Copilot、ChatGPT）改变开发方式

**核心矛盾**：AI 算力需求爆炸，但传统 CPU 架构遇瓶颈。GPU + 异构计算成为答案。

## 八、三条线的推动关系总览

| 年代 | 硬件 | 操作系统 | 软件/编程 |
| :--- | :--- | :--- | :--- |
| 1950s | 晶体管计算机 | 批处理监控程序 | 机器码/汇编 |
| 1960s | 集成电路 | 分时系统（CTSS/Multics） | FORTRAN/COBOL |
| 1970s | 微处理器 | Unix 重写 | C 语言 |
| 1980s | IBM PC / ARM | MS-DOS / Mac System | GUI 应用井喷 |
| 1990s | PC + 互联网 | Linux / Windows 95 | Web / 开源 |
| 2000s | ARM + GPU | iOS / Android | 移动 App / 深度学习萌芽 |
| 2010s+ | GPU / TPU / RISC-V | Linux 统治服务器 | AI / 自然语言编程 |

## 九、关键时间节点纠错清单

1. **第一台晶体管计算机**：1953 年（不是真空管的 ENIAC）；当时没有现代 OS，只有批处理监控程序
2. **汇编 vs 编译器**：汇编 1950 年代就有，编译器 1960 年代成熟
3. **Linux 时间**：1991 年（不是 1970-80 年代）；1970 年代是 Unix
4. **C 语言与 Unix 重写**：C 是 1972 年，Unix 用 C 重写是 1973 年——OS 可移植性的起点
5. **ARM 时间线**：1983 年诞生，真正爆发是 2007 年 iPhone 之后
6. **GPU 转折点**：CUDA 2006 年发布，GPU 从 3D 渲染走向通用计算

## 十、一句话总结

> 硬件从真空管 → 晶体管 → 集成电路 → 微处理器 → 多核/GPU → AI 加速器；操作系统从批处理 → 分时 → Unix → Linux/Windows → 移动 OS → 异构 OS；软件从机器码 → 汇编 → 高级语言 → GUI → Web → 移动 App → AI。三条线互相推动：硬件提供算力，OS 管理算力，软件消费算力。
