# 滤波器量化误差笔记：位数截断后的每一步

> 配套演示图：`量化误差演示四联图.png`（同文件夹）。所有数值均为本机 Python/scipy 真实仿真结果。

## 一、量化发生在三个地方

| 量化类型 | 发生在哪 | 主要体现 |
|---|---|---|
| 系数量化 | 设计完成后，把系数存成有限位宽 | 幅频响应图（最直观） |
| 输入/输出量化 | ADC 进、DAC 出，信号本身被截断 | 频谱底噪 |
| 运算量化 | 内部每次乘加（MAC）结果的截断/舍入 | 时域、频谱杂散 |

## 二、系数量化的链条（FIR）

1. 理想滤波器 = double 精度，阻带是干净深谷（如 -100dB）
2. 量化 = 每个系数只保留 B 位小数，引入最多 ±2⁻⁽ᴮ⁺¹⁾ 误差
3. 频响 H(ω) 是系数的函数 → 系数误差被"搬运"到频响上
4. 阻带深谷变成**"阻带地板"**：一片锯齿状毛刺
5. **经验公式：阻带地板 ≈ -6 dB/bit**

实测（FIR 101 阶，设计 100dB 阻带）：

```
16 bit: 阻带地板 -60.3 dB   还能用
12 bit: 阻带地板 -58.3 dB
 8 bit: 阻带地板 -40.5 dB   明显变差
 6 bit: 阻带地板 -27.2 dB   已废
```

结论：想要 -60dB 以上阻带，系数位数就下不来 16 位。

## 三、IIR 的链条：极点移动 → 不稳定

IIR 有反馈，系数误差扰动分母多项式 → 极点移动。

- 椭圆/切比雪夫滤波器极点都贴着单位圆 → 对系数误差极敏感
- 某个极点半径 > 1 → **滤波器不稳定，输出指数增长直到溢出**

实测（10 阶椭圆，设计 100dB 阻带，量化到 16 位）：

```
直接型(Direct-Form II): 极点半径 1.2147   ← 越出单位圆！不稳定
SOS 级联型:             极点半径 0.9821   ← 稳定
```

## 四、最阴险的坑：频响图会撒谎

量化到 16 位、极点半径 1.21（已越界）时，`freqz` 画出的幅频曲线仍然正常（-99dB）。

原因：频响是按系数多项式**代数求值**，不关心稳定性。

**只有时域图才现原形**——输入单位脉冲，400 采样后：

```
直接型 16bit: y[399] = 1.7×10³²   爆炸式发散
SOS  16bit:   y[399] = -2×10⁻⁵    正常收敛
```

教训：**频域图在不稳定时会骗人，时域图不会。**

## 五、为什么 SOS 能救命

- 直接型：10 阶多项式求根是病态的，一个系数误差同时扰动全部极点
- SOS：拆成 5 个独立 2 阶节，每个节的极点只受本节 3 个系数影响，误差被局部化

所以所有 DSP 库的 IIR 都强制 SOS 结构——不是风格，是定点数下稳定性的硬要求。

## 六、另两种量化

**输入/输出量化**：信号截断引入量化噪声（功率 ≈ q²/12，q 为最低位步长），被滤波器按 |H(ω)|² 整形。图上：频谱底噪抬升。

**运算量化**：MAC 结果截断，IIR 反馈回路让噪声循环积累，严重时出现**极限环**——零输入输出也不归零，时域停不下来、频谱出现杂散谱线。

## 七、一句话总结

> 频响图上的干净深谷是 double 的世界；定点世界里，阻带长着地板，极点会搬家，时域会爆炸。看频响图之前，先问一句：系数是什么位宽？

## 八、在 MATLAB 里自己复现

Filter Designer → 设计滤波器 → **Set Quantization Parameters** → 把 Input/Output/系数改成 Fixed-point，从 16 位一路降到 8 位：

1. 阻带深谷先变"地板"（最显眼）
2. 通带纹波跟着变乱
3. IIR 且极点贴圆时：某位宽阈值以下，曲线突然"炸"出尖峰 → 极点越界
4. 切到时域看冲击响应：稳定 vs 发散的差别立刻现形
