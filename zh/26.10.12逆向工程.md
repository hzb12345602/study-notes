# 26.10.12 逆向工程入门：读懂汇编与链接产物

> 学习笔记。定位：初学方向，在既有基础上继续加深。
> 核心结论先行：**不是要会写汇编，而是要能读懂汇编，并且理解链接产物。**

逆向工程里，代码逻辑只是中间一层——**下面**是 ABI、目标文件、链接器、加载器，**上面**才是高级语义。只看逻辑不够，链接和符号体系才是骨架。

## 一、汇编要读到什么程度

不用背完整指令集，但要能识别常见模式。

### 寄存器与栈
- **x86**：`eax/ebx/ecx/edx/esi/edi/ebp/esp`
- **x64**：`rax~r15, rsp, rbp, rdi, rsi, rdx, rcx, r8, r9`

### 常用指令
`mov, lea, push/pop, call/ret, jmp/jcc, cmp/test, add/sub, xor, and/or, shl/shr, imul/idiv, movzx/movsx`

### 栈帧（识别函数边界）
```
push rbp
mov  rbp, rsp
sub  rsp, N
...
leave
ret
```

### 调用约定
- **x86**：`cdecl`（调用者清栈）、`stdcall`（被调者清栈）、`fastcall`、`thiscall`
- **x64 Windows**：前四个参数放 `rcx, rdx, r8, r9`，其余走栈；有 32 字节 shadow space；栈 16 字节对齐

### 高级结构
`if/else`、循环、`switch` 跳转表、虚函数调用（vtable）、异常处理（SEH / C++ EH）

目标：看到一段汇编，能说出"它在干什么"，而不是逐条翻译。

## 二、除了代码逻辑，还要懂链接与目标文件层

感觉需要看链接库、`.o` 输出位置、特殊字符——这是对的，属于**链接与目标文件层**。

### 编译链接流程
```
源文件 -> 预处理 -> 编译 -> 汇编 -> .obj/.o -> 链接 -> .exe/.dll/.so
```

### 目标文件里有什么
- **节区**：`.text` 代码、`.data` 已初始化全局、`.bss` 未初始化、`.rdata` 只读、`.idata` 导入、`.edata` 导出、`.reloc` 重定位、`.pdata` 异常、`.tls` 线程局部、`.CRT` 初始化
- **符号表**：函数名、变量名、局部/全局/外部符号
- **重定位表**：链接时把符号地址填上；静态库直接复制，动态库留导入表

### 库与链接
- **静态库**：`.lib` / `.a`，代码直接进可执行文件
- **动态库**：`.dll` / `.so`，运行时加载
- **导入库**：Windows 的 `.lib` 里含 `__imp_` 符号，指向 IAT
- **IAT/ILT**：导入地址表 / 导入查找表，逆向时看调用了哪些外部函数
- **启动代码**：`mainCRTStartup` → `__scrt_common_main` → `main`；全局构造在 `.CRT$XCU`

## 三、特殊字符是什么：名字修饰与链接器标记

- **C**：`_func`（cdecl）、`_func@4`（stdcall）、`@func@4`（fastcall）
- **C++**：`?func@@YAHH@Z`、`??_7Class@@6B@`（vtable）、`??_R`（RTTI）
- **导入**：`__imp_LoadLibraryA`、`__imp_load_`
- **异常**：`__CxxFrameHandler`、`_except_handler`
- **调试**：`.pdb`、`.debug_*`

看到这些不要慌，用 `undname`、`c++filt` 或 IDA/Ghidra 自动还原。

## 四、实际逆向怎么做

1. **不要从头读全部汇编**——先看导入表、字符串、交叉引用
2. 用 IDA/Ghidra 反编译辅助，关键处回看汇编
3. 自己写小 C 程序，用 `/FA` 或 `gcc -S` 生成汇编，用 `dumpbin` / `objdump` / `readelf` 看 `.obj`，对比理解
4. 工具：`dumpbin`、`objdump`、`readelf`、`nm`、`strings`、CFF Explorer、PE-bear、x64dbg、WinDbg

## 五、结论

**需要能读懂汇编和链接产物，但不必成为汇编高手。**

逆向 = 代码逻辑 + ABI + 链接/加载 + 工具链。

`.o` 输出、库、特殊字符——这些正是从"会看代码"到"看懂二进制"的关键一层。如果只停在代码逻辑，遇到静态库、动态导入、名字修饰、重定位就会卡住。
